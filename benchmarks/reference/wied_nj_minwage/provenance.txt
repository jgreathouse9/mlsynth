source: author's replication script (reproduce_empirics.py, D. Wied), run against
        an IPUMS-CPS Basic Monthly extract 1989-1993 supplied by the repo owner
paper:  Wied, Dominik (2026), "A Synthetic Control Approach to Conditional
        Distributional Treatment Effects", arXiv:2606.09625v1
data:   IPUMS-CPS Basic Monthly, 1989-1993 (Flood et al. 2025). The raw extract
        (~145 MB gzipped, 8.78M person-records) is NOT vendored. What is stored
        here is the *estimation sample* produced by the author's own
        prepare_sample() + select_states(), which is the exact input the
        estimator consumes -- nothing downstream reads the raw microdata.

nj_estimation_sample.parquet
  381,953 rows x 7 cols, 43 states (NJ + 42 donors) x 4 policy years
  columns: STATEFIP int16, t int8, logwage, educ_yrs, exper, e_std, x_std
  policy years run April-March: t=1 Apr89-Mar90 ... t=4 Apr92-Mar93 (post)
  New Jersey cell sizes 3852 / 3998 / 4031 (pre) and 3905 (post)
  -- all four match the paper's stated sizes exactly.

  MUST be float64. The Gram matrix has kappa ~ 9.6e4 and the closed-form weight
  solve amplifies relative input error by ~1e6. A float32 round-trip (relative
  error ~6e-8) moves donor weights by 0.12-0.17 -- Florida 0.515 -> 0.40 -- while
  leaving the estimands nearly intact. Verified by jitter experiment; see the
  replication page. float64 costs nothing here: both files are ~1.56 MB, because
  the columns are dictionary-encoded.

nj_meta.json
  n, J, the 43 state FIPS codes, and the four pooled standardisation constants
  (me, se, mx, sx) needed to map (education, experience) to evaluation points.

NOT exactly reproducible, and why: the Gaussian-process critical values c90.
Obtained here as 245.5 and 240.5 against the paper's 245.3 and 241.7. sup_test
builds L = V diag(sqrt(ev)) via np.linalg.eigh, whose eigenvector SIGNS are
implementation-defined; a different LAPACK build gives a different L and hence a
different realisation for identical Gaussian draws, even with the seed fixed.
Measured effect ~0.2-0.5% on c90, which covers both gaps. Test statistics (Tn)
never touch an eigendecomposition and are exact. So: pin Tn, f-hat, LCB and the
weights tightly; pin c90 and p-values loosely.
